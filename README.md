# Takhti Grow

Android app (Flutter + Firebase) that turns Takhti's neuroscience videos into one small daily lesson:
**read the key idea → watch a short clip → do one action → reflect in the evening → optional quick check.**

Pilot: 3 onboarding screens + 4 lessons, adults (18+), English UI.
